# Trova Travel Hero — React + Tailwind CSS

A responsive recreation of the Trova Travel landing hero, built with React, Vite and Tailwind CSS. It includes the animated Trova intro, full-screen mountain hero, responsive navigation, and a functional **Find your next hike** route leading to a styled hikes page with filters and trip details.

## Run

```bash
npm i
npm run dev
```

## Build

```bash
npm run build
```

## Main structure

```text
src/
├── components/
│   ├── Header.jsx
│   ├── IntroAnimation.jsx
│   ├── Hero.jsx
│   └── HeroBelow.jsx
├── data/
│   ├── heroData.js
│   └── hikes.js
├── pages/
│   ├── Home.jsx
│   └── Hikes.jsx
├── App.jsx
├── main.jsx
└── index.css
```

The implementation is inspired by the public Trova page structure and visual language; it does not copy Framer source code.
